# 真机验收清单

> 模拟器**无摄像头**，扫描类行为一律在真机验收。每项勾选需附机型 + iOS 版本 + 结果截图或录屏。
> 未勾完不算发布。

## 环境

- [ ] 机型与芯片已记录（例：iPhone 15 Pro / A17 Pro）
- [ ] iOS 版本已记录（≥ 17.0）
- [ ] 构建来源与 commit hash 已记录

## 拍摄与检测

- [ ] 权限：首次使用相机时按需弹窗，拒绝后 App 不崩、不循环弹窗
- [ ] 平面文档：边角检测稳定，四角贴边
- [ ] 弯曲书页：不做校正时结果可预期（不出现扭曲假象）
- [ ] 低光：可拍、结果可判断（不静默失败）
- [ ] 证件：边框检测不误判
- [ ] 手写：几何结果与印刷件一致

## 导出

- [ ] PDF 导出可被系统预览打开，页序正确
- [ ] 导出到相册/文件成功，且在用户拒绝权限时给出解释
- [ ] 大页数（≥ 20 页）导出无内存峰值异常

## 性能与稳定性（门槛见 docs/acceptance.md）

- [ ] 冷启动到可拍 ≤ 目标值（待定，随首批实现确定）
- [ ] 单页处理耗时 P50 / P95 已记录
- [ ] 峰值内存增量已记录（有模型时含模型常驻）
- [ ] 连续 20 页扫描无崩溃、无内存持续增长

## 隐私

- [ ] 关闭网络后全部核心流程可用（证明无隐式上传）
- [ ] `PRIVACY.md` 与 App Store 隐私问卷逐项一致
