# 验收标准（已拍板：方案 B）

> 方案 B = **以真实使用效果为准**，论文级指标只在对外对比时补跑。不追求与论文数字对齐，
> 追求「同一批样张，这一版比上一版更好」。

## 三条硬标准

1. **单测覆盖纯逻辑**：几何（四角→单应、网格采样）、管线编排、错误路径必须有单测，
   且能在本地 `swift test --package-path Sources/DDScannerCore` 跑通（无模拟器）。
2. **固定样张集版本间人工 A/B**：
   - 样张集 20–30 张，覆盖：平面文档 / 书页弯曲 / 低光 / 证件 / 手写。
   - 样张集**入库固定**（同一批图跨版本可比）；每张记录拍摄条件。
   - 每个版本出结果图，人工 A/B「这版 vs 上版」→ 结论写入发布说明（赢/平/输，逐张或分组）。
3. **真机性能基准**：每次引入模型或改动推理路径，必须在真机跑基线（耗时 P50/P95、峰值内存、
   机型），报告格式见 `docs/model-supply-chain.md`。

## 不属于验收标准（明确排除）

- 论文指标（CER / MS-SSIM / PSNR 等）**不作为每版门槛**；仅在对外对比、发布说明需要时补跑。
- 模拟器截图比对、像素级视觉回归**不作为验收手段**（模拟器无摄像头，取证无效）。
- 单张「看起来更好」不作为结论：必须落在固定样张集的 A/B 上。

## 与门禁的关系

- 门禁（G1–G9）保证**工程可交付**；本文保证**效果可判断**。两者缺一不可，但互不替代。
- 真机验收清单：`docs/device-acceptance-checklist.md`（逐项勾选，未勾完不算发布）。
